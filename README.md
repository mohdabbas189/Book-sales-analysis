# Book-sales-analysis
👇

📚 Book Sales Analysis Project
📌 Overview

This project analyzes a book sales dataset to understand publishing trends, author performance, ratings, and revenue generation. The goal is to extract actionable insights using Python-based data analysis.

📂 Dataset Description

The dataset contains information about books, authors, ratings, sales, and publishers.

🧾 Columns:
Column	Description
Book Name	Title of the book
Author	Author(s) of the book
language_code	Language of the book
Author_Rating	Rating level of author (Novice, Intermediate, etc.)
Book_average_rating	Average rating of the book
Book_ratings_count	Number of ratings received
genre	Genre classification
gross sales	Total sales revenue
publisher revenue	Revenue earned by publisher
sale price	Price per unit
sales rank	Ranking based on sales
Publisher	Publishing company
units sold	Total units sold

Python 🐍
Pandas
